# Easy console practice coverage

The complete bank has been rebuilt from the beginning following the teacher's rejection of the previous language. There are 90 Easy problems, ten per existing interest. These are program briefs for a developer, with familiar purposes, concrete rules, labelled test values or supplied list data, and an exact expected result. They do not address the reader as the customer or introduce a fictional individual as the protagonist.

Each needed subject term is introduced in ordinary language. Pixels are tiny picture dots, frames are the pictures in a video, and a discount is the amount taken off a price. Formulae, units, limits and the meaning of each requested output are stated. Kelvin and the abstract input-assumption paragraphs are absent. Written briefs, explanations, questions, choices, feedback and output labels use no colons. Python keeps the colons required by its syntax and numeric formatting.

The new bank includes 396 explained code lines, 180 authored stages, 270 current-line understanding questions and 90 causal prediction checkpoints. Every checkpoint has a separate identity. A correct answer unlocks the next view without advancing automatically. Wrong or unanswered checkpoints block forward routes, including later-stage jumps. Predictions precede the next code and explanation. The complete cumulative code, syntax colours, Remember card, retained last view and existing generated typing/selected answer sounds remain part of the experience.

The 64 Exam problems and their guide banks are byte-preserved. Medium and Hard remain empty. This Easy bank uses short console Python programs covering input/output, conversions, arithmetic, text, decisions, repetition and lists. It does not introduce functions, validation loops, files, SQL, GUIs or runtime services. The new solutions are deliberately authorised replacements within Easy scope.
