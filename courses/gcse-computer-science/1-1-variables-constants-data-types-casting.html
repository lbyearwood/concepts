1.1 Variables, constants, data types and casting

How programs store values and choose the right type of data.

Programming foundations

Learn how named values help a program remember information, update it and use it correctly.

Keywords

Variable

A named storage location whose value can change while a program runs.

Constant

A named value that stays fixed while a program runs.

Identifier

The name used to identify a variable or constant.

Assignment

Storing a value in a named variable.

Data type

The kind of value stored and the operations that can be used with it.

Casting

Converting a value from one data type to another.
